Add products

Products are the heart of your shop. Here is how to add one that looks good in this theme.

Add a product

  1. In Shopify choose Products → Add product.
  2. Type a title, for example Barrier Serum.
  3. Write a description: what it does, who it is for, how to use it, key ingredients.
  4. Drag in 3 to 5 photos. The first photo is the one shown on product cards. The second is shown when someone hovers over the card.
  5. Set the price. To show a sale, type the old price in Compare-at price. The theme shows the badge for you.
  6. Under Variants, press Add options like size or color if the product comes in more than one version. See below.
  7. Add the product to a collection on the right side, then press Save.

Photo order that works

  1. A clean photo of the product on a plain background.
  2. The product in a scene (lifestyle photo).
  3. The texture of the product.
  4. The product being used.
  5. The size next to a hand (optional).

Options and variants

If a product comes in different shades or sizes:

  1. Press Add options like size or color.
  2. Type the option name. Use Shade or Color for colours. Use Size for sizes.
  3. Type each value: Porcelain, Petal, Honey or 30 ml, 50 ml.
  4. Set a price and stock for each variant and, if you like, attach a photo to each one.

Want round colour swatches?

Name the option Color, Colour, Shade or Tone and follow Colour swatches. Any other name, such as Size, shows as text buttons.

Sold-out products

Set stock to 0 and the theme marks the product as sold out. On the product page a sold-out swatch or size is crossed out so shoppers see it is not available.
