10-step quick start

The shortest path from a new theme to a shop you are proud of. Do these in order.

  1. Add your logo. In the editor open Header (the top section) and upload your logo. Add a second light logo if the header sits over a dark image. See Header and menu.
  2. Add products. In Shopify go to Products → Add product. Use 3 to 5 photos, a clear title and a short description. See Add products.
  3. Add colours or shades. If a product comes in colours or shades, add an option called Color or Shade and follow Colour swatches.
  4. Make collections. Go to Products → Collections and create groups such as Skincare, Makeup and Sale. See Collections.
  5. Build the menu. Go to Content → Menus and edit Main menu. Then select it in the Header. See Header and menu.
  6. Set up the home page. Open the Home page in the editor and replace the sample images and text, section by section. See Home page.
  7. Create your pages. Add About, Contact and FAQ in Online Store → Pages. See Pages.
  8. Set the cart. In Theme settings open Cart and choose what happens after "Add to cart". See Cart.
  9. Check on a phone. Use the phone icon at the top of the editor, or open your store on your phone.
  10. Publish. In the theme library press Publish.

Do not leave sample content

The theme ships with sample headlines and images. Replace all of it before you publish. Shoppers notice, and Shopify's Theme Store requires real text on live demo stores.
