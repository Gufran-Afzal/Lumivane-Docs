Colour swatches and shades

Swatches turn a list of shade names into small coloured circles. This page explains how they work and how to set them up, even if you have never done it before.

What shoppers see

On a product page, an option such as Shade shows as round colour buttons with the chosen name written next to the title (for example Shade: Honey). The chosen swatch has a ring and a tick. Hover over a swatch to see its name. A sold-out swatch is faded and crossed out.

On a product card, up to four small dots appear under the title, then a number such as +2 for the rest.

The 3 ways to give a swatch its colour

The theme looks for a colour in this order and uses the first one it finds.

Order Method Best when
1 Shopify's own swatch colour on the option value You use Shopify's product category with a Color option. This is the recommended way.
2 Swatch colors list in Theme settings Your shades are custom names such as Honey or Cocoa.
3 A plain colour word such as Black, Red, Navy Your values are simple colour names. Nothing to set up.

If a value has no colour from any of the three methods, the whole option shows as text buttons instead. This is on purpose, so you never see a blank circle.

Method 1: Shopify's swatch colour

  1. Open the product in Shopify and set its Category. Shopify only offers swatch colours for categories that have a Color attribute.
  2. Under Variants add the option and choose Color from the list that Shopify offers.
  3. Pick each colour from Shopify's list. Shopify stores a swatch colour for each one.
  4. Save. The theme picks the colours up automatically.

Note

Not every beauty category offers the Color attribute, and the colour names Shopify offers may not match your shade names. If that happens, use Method 2. It always works.

Method 2: type your own colours (most common for makeup)

  1. In the theme editor click the paintbrush icon → Swatches.
  2. Find the box called Swatch colors.
  3. Type one shade per line, as Name: #colour. Example: 
    01 Porcelain: #F3D7C6
02 Petal: #EBC3A8
03 Honey: #D9A47E
04 Sienna: #B77A55
  4. Press Save.

Good to know

  • The name on the left must match the option value in your product. Capital letters do not matter.
  • A leading number is optional. A product value Honey matches the line 03 Honey, and the other way round.
  • To find a colour code, take a photo of the product swatch, open it in any free colour picker and copy the code that starts with #.
  • Use the same list for all products, so a shade always has the same colour.

Method 3: plain colour words

If your option values are words like Black, Navy, Rose or Gold, you do not need to set anything up. The theme knows these common words: black, white, red, blue, green, yellow, orange, purple, pink, brown, grey, beige, cream, ivory, gold, silver, bronze, navy, teal, olive, burgundy, maroon, coral, peach, nude, tan, khaki, lavender, lilac, mint, rose.

Choose which options become swatches

In Theme settings → Swatches the box Options shown as swatches lists the option names that should become colour swatches. The default is Color, Colour, Shade, Tone. Add another name, for example Finish, separated by a comma.

Choose the swatch shape

Under Swatch shape choose Round (recommended), Square or Droplet.

Show swatches on product cards

Open Theme settings → Product tiles and turn Show color swatches on or off.

Swatches with photos

Instead of colours you can show a small photo of each variant, with its name underneath. This suits products where the bottle or box changes, such as scents.

  1. In Shopify attach a photo to each variant (open the variant row and add an image).
  2. In the theme editor open a product page and click the Variant picker block.
  3. Set Style to Variant images and press Save.

Check your work

  1. Open a product page that has the option.
  2. You should see round colours and the chosen name next to the option title.
  3. Click another colour. The name, the product photo and the price update.
  4. Hover over a swatch to see its name.

Troubleshooting

What you see Why Fix
Text buttons instead of circles One value has no colour Add every value to Swatch colors or give it a Shopify swatch
Text buttons even though I added colours The option is not named Color, Shade, Tone or Colour Rename the option, or add its name to Options shown as swatches
A circle is the wrong colour A colour code is wrong, or the name matches another line Check the code and the spelling of the name
A swatch has a line through it That variant is sold out Add stock or leave it. This is expected.
No dots on product cards The setting is off, or the option does not qualify Turn on Show color swatches and check the points above
