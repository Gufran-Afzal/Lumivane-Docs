Install the theme

Get Lumivane into your store and choose a look. This takes about five minutes.

Upload the theme

  1. In your Shopify admin, open Online Store → Themes.
  2. Scroll to Theme library and press Add theme → Upload zip file.
  3. Choose the lumivane.zip file you downloaded. Do not unzip it.
  4. Wait until the upload finishes. The theme appears in the theme library.
  5. Press Customize on the new theme to open the editor.

Upload the zip, not the folder

Shopify only accepts a single .zip file. If you see an error about missing files, check that you did not zip a folder that contains the theme folder. The zip should open straight to the folders assets, config, layout and so on.

Choose a preset

  1. In the editor, click the paintbrush icon on the left. This is Theme settings.
  2. Click Change theme style at the top.
  3. Pick Lumivane, Nightbloom or Fernmist.
  4. Press Save.

What changes when you switch presets

Colours, button shapes and the page-change animation change. Your products, pages and text stay exactly as they are.

Preview before you publish

Press the three dots next to Customize in the theme library and choose Preview. Click around: the home page, a collection, a product, the cart. When you are happy, press Publish.
