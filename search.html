Search

The theme shows search results while shoppers type.

Open Theme settings → Search.

Setting What it does
Enable search suggestions Shows matching products as the shopper types.
Trending searches Words shown as buttons before the shopper types, separated by commas. Example: Serum, SPF, Lip oil.
Show vendor Shows the brand name in results.
Show price Shows the price in results.

Make search better

  • Use clear product titles and add product types and tags.
  • Install Shopify's free Search & Discovery app to add synonyms, such as "moisturiser" and "moisturizer", and to set up filters.
  • Open Search page in the editor to change how many results show per page.
