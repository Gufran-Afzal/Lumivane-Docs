Text and languages

Change any word the theme shows, or add more languages.

Change a word

  1. In the theme library press the three dots next to your theme, then Edit default theme content.
  2. Type a word, such as cart, in the search box.
  3. Change the text and press Save.

Add a language

  1. In Shopify go to Settings → Languages → Add language.
  2. Install Shopify's free Translate & Adapt app and translate your products, pages and theme text there.
  3. In the theme editor turn on Show language selector in the Header.
